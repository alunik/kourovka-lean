# Credit corrections

[Repository](../README.md) · [Research and credit](research-and-credit.md)

This process covers attribution for the six Nilradical v0 results listed
in the [research and credit policy](research-and-credit.md). An agent's
literature search can miss contributors, earlier results or a prior solution.

## Report missing or mistaken credit

[Open a credit correction issue](https://github.com/alunik/kourovka-lean/issues/new?template=credit_correction.md).
Include the affected result and revision, the credit you believe is missing
or mistaken, and supporting references. Exact pages, theorem numbers,
public dates and stable links help us assess whether an earlier result
answers the same question and scope.

GitHub issues are public. Please provide bibliographic evidence without
posting private correspondence or personal contact details.

## Review and updates

A human reviews each report against the cited sources. A report is not
automatically accepted, and an attribution or priority question may remain
unresolved while the evidence is checked.

An accepted correction receives a dated entry below identifying the result,
what changed, the supporting sources and the public issue. The corresponding
website and repository records are updated and linked to that entry. If an
earlier solution changes a novelty assessment, the discovery catalogue is
updated accordingly.

Previously published source revisions, approval records and verification
receipts are preserved. Corrections explain and link the change rather than
silently rewriting those records.
