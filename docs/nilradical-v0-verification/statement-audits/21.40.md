## Source comparison and exact claim

For an arbitrary subgroup G of GL(n,Q) with finitely many automorphism orbits, the Notebook asks whether G is virtually soluble. It imposes no finite-generation assumption.

Every such rational linear group has a normal subgroup K of actual finite index at most (2n+1)^(n^2), which is torsion-free nilpotent of class at most n-1 and is simultaneously conjugated into the upper-unitriangular matrices by one rational P. Virtual solubility follows. For every number field, the corresponding finite-orbit hypothesis gives a finite-index torsion-free nilpotent subgroup.

## Definition, quantifier, and witness checks

1. HasFiniteAutomorphismOrbits uses the quotient by the full MulAut G evaluation action on the subgroup carrier. The Mathlib action is literally automorphism application; it does not restrict automorphisms to ambient matrix conjugation or rational algebraic automorphisms.

2. The public rational quantifier covers every n : Nat and every subgroup of GL(Fin n,Q). There is no finite, finite-generation, solvability, or rank assumption on G. The finite hypothesis applies to the orbit quotient only.

3. StructuralConclusion separately asserts K.FiniteIndex and its numerical bound. Mathlib FiniteIndex requires nonzero natural index, which rules out the infinite-index default zero. Similarly, explicit Group.IsNilpotent precedes the class bound, ruling out the default zero class for nonnilpotent groups.

4. The quantifier order is one K and one rational invertible matrix P for all g in K. IsUpperUnitriangular enforces diagonal 1 and every strictly lower entry 0. The solution builds the trace kernel from actual matrices and a trace-pairing ideal, then applies one rational flag to the whole ideal.

5. The finite-order predicate was checked in Mathlib: it means some positive power is one. The explicit implication IsOfFinOrder g -> g = 1 is exactly torsion-freeness, not merely absence of a selected prime torsion.

6. Dimension zero is included. Natural subtraction makes n-1 zero; the zero-dimensional general linear group is trivial and the index bound is 1. There is no dimension-positive hidden premise in the public endpoint.

7. ConjugateStructure uses an injective conjugation homomorphism and transfers nilpotence, the class bound, and torsion-freeness from the unitriangular image to the same K. NumberFields faithfully restricts scalars, transports the full abstract orbit condition across a group isomorphism, and transfers actual finite index and structure back.

8. The conditional internal _of_rational_structure lemma is discharged in public numberField_structure by structural_theorem. Neither public number-field endpoint retains that extra premise. No bound in terms of the original number-field dimension is promised.

## Exact frozen statement

[Standalone snapshot](frozen-statements/P21_40.lean.txt).

```lean
import Mathlib.Algebra.Group.Action.End
import Mathlib.GroupTheory.GroupAction.Defs
import Mathlib.GroupTheory.Nilpotent
import Mathlib.GroupTheory.Torsion
import Mathlib.LinearAlgebra.Matrix.GeneralLinearGroup.Defs

/-!
# Problem 21.40

Dantas and de Melo ask whether a subgroup of `GL_n(ℚ)` with finitely many
orbits under its full abstract automorphism group is virtually soluble.
The question is recorded in the 21st edition of the Kourovka Notebook,
version 46 (1 September 2026), page 173. No finite-generation hypothesis
is imposed. We do not assert that the question first appeared there.
-/

namespace Kourovka.P21_40

/-- Finitely many orbits of the full abstract automorphism group on the group. -/
def HasFiniteAutomorphismOrbits (G : Type*) [Group G] : Prop :=
  Finite (MulAction.orbitRel.Quotient (MulAut G) G)

/-- A group is virtually soluble if it has a soluble subgroup of finite index. -/
def IsVirtuallySolvable (G : Type*) [Group G] : Prop :=
  ∃ K : Subgroup G, K.FiniteIndex ∧ Group.IsSolvable K

/-- The full question in Kourovka Notebook Problem 21.40, including dimension zero. -/
def NotebookStatement : Prop :=
  ∀ (n : ℕ) (G : Subgroup (Matrix.GeneralLinearGroup (Fin n) ℚ)),
    HasFiniteAutomorphismOrbits G → IsVirtuallySolvable G

/-- Upper unitriangular means diagonal entries one and entries below the diagonal zero. -/
def IsUpperUnitriangular {n : ℕ} (A : Matrix (Fin n) (Fin n) ℚ) : Prop :=
  (∀ i, A i i = 1) ∧ ∀ i j, j < i → A i j = 0

/-- The quantitative structural strengthening of the Notebook question.

There is one normal finite-index subgroup and one rational change of basis
for all its elements. Finiteness of the index is explicit: the numerical
bound alone would not rule out mathlib's value zero for an infinite index.
-/
def StructuralConclusion {n : ℕ}
    (G : Subgroup (Matrix.GeneralLinearGroup (Fin n) ℚ)) : Prop :=
  ∃ K : Subgroup G, K.Normal ∧ K.FiniteIndex ∧
    K.index ≤ (2 * n + 1) ^ (n ^ 2) ∧
    Group.IsNilpotent K ∧ Group.nilpotencyClass K ≤ n - 1 ∧
    (∀ g : K, IsOfFinOrder g → g = 1) ∧
    ∃ P : Matrix.GeneralLinearGroup (Fin n) ℚ, ∀ g : G, g ∈ K →
      IsUpperUnitriangular
        ((P⁻¹ * (g : Matrix.GeneralLinearGroup (Fin n) ℚ) * P :
          Matrix.GeneralLinearGroup (Fin n) ℚ) : Matrix (Fin n) (Fin n) ℚ)

end Kourovka.P21_40
```
