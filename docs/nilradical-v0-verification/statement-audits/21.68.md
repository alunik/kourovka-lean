## Source comparison and exact claim

Kida conjectures that finite semiabelian groups are monomial. The Notebook defines semiabelianity by an actual increasing subgroup chain, each next group being an abstract quotient of an abelian semidirect product with its predecessor. Kida, On semiabelian groups, Definition 2.1 additionally explicitly calls the auxiliary abelian groups finite.

The concrete group G of order 2592 has a semiabelian subgroup chain and a nonzero irreducible complex representation of dimension 8 which is not isomorphic to the induction of any linear character of any subgroup. Hence the universal finite-group assertion fails.

The [Notebook v46](https://arxiv.org/abs/1401.0300v46), printed page 177, was compared directly with its local PDF text (physical PDF page 177; local extraction (retained privately; [source PDF](https://arxiv.org/pdf/1401.0300v46)), lines 8436–8441). Source SHA-256: `498c2443bcee6ca398430935c87c97b6f99d0b1a6e5cb8f637d188a1827115da`.

The reviewed website summary and scope are preserved in [the mathematical-scope snapshot](sources/reviewed-site-mathematical-scope.json). They match the formal scope:

## Definition, quantifier, and witness checks

1. NotebookStatement quantifies over groups with an explicit Finite instance; no cardinality bound or solvability premise is added. IsSemiabelian uses subgroups of that actual G, starts at bottom, ends at top, and requires monotonicity. Each step supplies a surjective homomorphism from A semidirect the preceding subgroup, exactly the abstract-quotient condition.

2. IsSemiabelianStep does not demand that A be finite, matching the literal Notebook. This difference from Kida Definition 2.1 does not undermine this counterexample: its chain is built from the explicitly finite factors C3, V4, E, and A by injective semidirect inclusions. For a finite target the general definition can also be reduced to a finite abelian factor using the image of A; that equivalence is explanatory here, not an extra formalized endpoint.

3. The constructed G is the ternary augmentation kernel A semidirect W; A has order 27 and W order 96. The finite instances come from concrete finite semidirect-product carriers. card_G proves 2592, and G_semiabelian repeatedly constructs actual subgroup chains rather than assuming a closure-class interface.

4. Monomiality is expressed using finite-dimensional complex representations, Simple, subgroup linear characters theta : L ->* C units, and a categorical isomorphism to induction. The linear-character action was inspected: it is scalar multiplication on the one-dimensional field carrier. TauCeti.indFDRep is a finite-dimensional shrink of Mathlib Rep.ind with an explicit equivariant comparison, not a dummy induction operator.

5. The external FDRep.simple_iff_isIrreducible bridge identifies categorical simplicity with the ordinary nonzero invariant-subspace notion. The concrete witness is the induction of inertiaRep, which inflates a two-dimensional quaternion representation and twists by the extended coordinate character.

6. The Solution proves simplicity and dimension eight for that same witness. Its nonmonomial obstruction is universal over all inducing subgroups and all linear characters. The degree/index argument uses the actual finite normal subgroup of order 27, exact inertia, and the proved absence of index-two subgroups in the quaternion complement.

7. No minimality claim, catalogue group identification, character-table oracle, or external finite-check premise is part of the final theorem. Finite algebraic calculations are proof terms subject to the separate strict replay.

## Exact frozen statement

[Standalone snapshot](frozen-statements/P21_68.lean.txt).

```lean
import Mathlib.GroupTheory.SemidirectProduct
import Mathlib.Analysis.Complex.Basic
import Kourovka.External.TauCeti.RepresentationTheory.Induction.FiniteDimensional
import Kourovka.External.TauCeti.RepresentationTheory.LinearCharacter

/-!
# Problem 21.68

M. Kida asks whether every finite semiabelian group is monomial. Semiabelian
means the subgroup-chain definition in the Kourovka Notebook and Definition
2.1 of *On semiabelian groups* (2025). Monomiality is expressed in its standard
representation form: every irreducible complex representation is induced
from a one-dimensional character of a subgroup.
-/

open CategoryTheory

namespace Kourovka.P21_68

/-- An abelian semidirect product with the preceding group maps onto
the next group. The source definition only asks for an abstract quotient. -/
def IsSemiabelianStep (H K : Type) [Group H] [Group K] : Prop :=
  ∃ (A : Type) (_ : CommGroup A)
    (α : H →* MulAut A) (f : A ⋊[α] H →* K), Function.Surjective f

/-- The actual subgroup-chain definition of semiabelianity. -/
def IsSemiabelian (G : Type) [Group G] : Prop :=
  ∃ (n : ℕ) (C : ℕ → Subgroup G),
    C 0 = ⊥ ∧ C n = ⊤ ∧ Monotone C ∧
    ∀ i < n, IsSemiabelianStep (C i) (C (i + 1))

/-- A representation induced from a linear character of a subgroup. -/
def IsMonomialRepresentation {G : Type} [Group G] [Finite G]
    (V : FDRep ℂ G) : Prop :=
  ∃ (L : Subgroup G) (θ : L →* ℂˣ),
    Nonempty (V ≅ TauCeti.indFDRep (FDRep.ofLinearCharacter θ))

/-- Every irreducible complex representation of the finite group is monomial. -/
def IsMonomial (G : Type) [Group G] [Finite G] : Prop :=
  ∀ V : FDRep ℂ G, Simple V → IsMonomialRepresentation V

/-- Kida's conjecture, Kourovka Notebook problem 21.68. -/
def NotebookStatement : Prop :=
  ∀ (G : Type) [Group G] [Finite G], IsSemiabelian G → IsMonomial G

end Kourovka.P21_68
```
