# Problem 21.3: first question

**Answer: yes**, for both `S_n` and `A_n`, uniformly over all pairs of
soluble subgroups, once the degree is sufficiently large.

## Source and scope

M. Anagnostopoulou-Merkouri and T. C. Burness, *The Kourovka Notebook*,
21st edition, Problem 21.3, p. 167. Source:
[arXiv:1401.0300v46](https://arxiv.org/abs/1401.0300v46).

The first question asks whether, for `G = S_n` or `A_n` and soluble
subgroups `H, K ≤ G`, sufficiently large `n` guarantees an `x ∈ G`
with `H ∩ x⁻¹Kx = 1`. This entry answers that first question.
The subsequent question asking for the specific threshold `n ≥ 21`
is not asserted by this theorem.

## Formal statement

[`FirstQuestion`](../Kourovka/Problems/P21_03/Statement.lean) asserts the
existence of one natural number `N` such that, for every `n ≥ N`, both
the symmetric and alternating conclusions hold for every pair of soluble
subgroups. The cutoff precedes the subgroup quantifiers.

- `Equiv.Perm (Fin n)` is `S_n`.
- `Group.IsSolvable H` is solubility of the subgroup as a group.
- `Disjoint H K` for subgroups means `H ⊓ K = ⊥`.
- `MulAut.conj x⁻¹ • K` is `x⁻¹Kx`.
- Subgroups of `A_n` are represented inside `S_n` with explicit containment
  hypotheses. The conjugating element is explicitly required to lie in
  `alternatingGroup (Fin n)`.

The public theorem is
[`Kourovka.P21_03.firstQuestion`](../Kourovka/Problems/P21_03/Solution.lean).
It has no classification or finite-certificate premise.

## Argument and source map

For each degree let `p_n` be the infimum, over soluble `H,K ≤ S_n`, of the
proportion of permutations `x` with `H ∩ x⁻¹Kx = 1`. The development proves
`p_n → exp(-9/2)`. Positivity of this limit gives a uniform eventual
existence statement in `S_n`.

The supporting argument embeds soluble actions into forest envelopes,
separates the transposition core from the remaining elements, and bounds
the latter's contribution uniformly by a quantity tending to zero. Core
counting supplies the lower limit; consecutive four-point blocks supply
the matching upper limit. A separate parity argument yields even
conjugators for the alternating case.

| Part | Supporting module in `Proof/` |
| --- | --- |
| Soluble primitive actions | `PrimitiveSolvable.lean` |
| Forest envelopes and support bounds | `ForestEnvelopeBounds.lean` |
| Symmetric probability limit | `Asymptotic.lean` |
| Even conjugators and combined eventual conclusion | `AlternatingAsymptotic.lean` |

Supporting declarations retain the namespace `Kourovka213` from the
original development; the public interface uses `Kourovka.P21_03`.
Only the dependency closure of the unconditional eventual theorem was
included. No numerical threshold modules or external certificates are
required to build this solution.
