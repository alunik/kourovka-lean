# Problem 21.106

[All problems](../../../README.md#problems) · [Contributing](../../../CONTRIBUTING.md)

## Problem

Is every parameter-free first-order formula with one free variable concise
in the class of residually finite groups? Here a formula is concise in a
group if finiteness of its set of values implies finiteness of the subgroup
generated by those values.

The question appears as Question 1 in Conte and Petschick's
[*Conciseness of first-order formulae*](https://arxiv.org/abs/2505.01411v1),
first submitted on 2 May 2025. It was subsequently listed by M. Petschick
as Problem 21.106 in the **New Problems** section of the
[21st-edition Notebook](https://arxiv.org/abs/1401.0300v46), printed page 183.

## Result and scope

**Negative.** In the integral Heisenberg group, an explicit positive,
parameter-free first-order formula defines exactly the two elements
`central 1` and `central (-1)`. They generate an infinite subgroup, while
the ambient group is residually finite.

The formalization proves the full negative answer. It includes actual
first-order syntax and its realization theorem, the exact value-set
characterization, and residual finiteness via finite quotient homomorphisms.
It requires no computational certificates or unproved group-theoretic
assumptions. The separate word-conciseness problem 21.105 is outside this
result's scope.

## Formal statement

[`NotebookStatement`](Statement.lean) quantifies over groups with mathlib's
`Group.ResiduallyFinite` instance and all formulae in the ordinary group
language with a single free-variable index, `Unit`. The language has exactly
multiplication, inversion, and the identity constant. It has no constants
naming elements of the counterexample.

`FormulaValues` uses mathlib's `FirstOrder.Language.Formula.Realize`.
`IsConciseIn` states that a finite value set has finite `Subgroup.closure`.
The public answer is
[`Kourovka.P21_106.not_notebookStatement`](Solution.lean).

The concrete formula in [Formula.lean](Proof/Formula.lean) has quantifiers
and matrix

\[
\exists a,b\;\forall g,h\;\exists u,v\;
\bigl(x=[a,b]\land[u,a]=1\land[v,b]=1
\land[u,b]=[g,h]\land[a,v]=[g,h]\bigr),
\]

where `[a,b]` abbreviates `a⁻¹ * b⁻¹ * a * b`. All variables other than
`x` are bound. The matrix is a conjunction of equations; the displayed
formula uses only positive logical connectives and quantifiers.

## Proof outline

Read [How the proof works](../../../docs/walkthroughs/21.106.md),
an informal account by **Nilradical v0**, generated after human statement
acceptance and labelled **Agent-generated exposition; not refereed**.

1. Define the Heisenberg group on integer triples with multiplication
   `(r,s,t)(r',s',t') = (r+r', s+s', t+t'+r*s')`. Its commutator is
   `(0,0,r*s'-s*r')`.
2. For a formula value, instantiate the universal quantifiers at the two
   standard generators. The four resulting determinant equations and the
   two-dimensional Plucker identity force the central coordinate to be an
   integer unit, hence `1` or `-1`.
3. Give explicit witnesses for both values. Embed the integers in the
   subgroup generated by them to prove that subgroup infinite.
4. Reduce all coordinates modulo a suitable positive integer to separate
   each nonidentity element in a finite quotient. This proves the standard
   residual-finiteness property.
5. Transfer the algebraic characterization through the first-order
   realization theorem and negate the public universal statement.
