## Question and claimed answer

The repository represents Conte and Petschick's question as: is every parameter-free first-order formula with one free variable concise in residually finite groups? A formula is concise when finiteness of its value set implies finiteness of the subgroup generated by that set.

Primary question sources to check: [Question 1, arXiv:2505.01411v1](https://arxiv.org/abs/2505.01411v1) and [Kourovka Notebook v46, problem 21.106, printed page 183](https://arxiv.org/abs/1401.0300v46). The question/source mapping here is taken from the repository's existing documentation; the human should inspect the originals.

**Claimed resolution:** negative. A parameter-free formula has exactly two values in the residually finite integral Heisenberg group, and these values generate an infinite subgroup. This does not resolve the separate word-conciseness problem 21.105.
